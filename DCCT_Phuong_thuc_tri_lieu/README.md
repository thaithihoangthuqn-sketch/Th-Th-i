# ĐCCT học phần Phương thức trị liệu (PTL024344) – Phụ lục 3 & 4

- `Phu_luc_3_4_Phuong_thuc_tri_lieu_2026.docx` – Phụ lục 3 (Hướng dẫn SV chuẩn bị bài, tự học) và Phụ lục 4 (Kế hoạch bài giảng) cho 16 bài; bản PDF kèm theo để xem nhanh.
- `src/` – nội dung (lessonsA.js: Phần A, B; lessonsC.js: Phần C) và script tạo file Word.
  Tạo lại: `cd src && node build.js ../Phu_luc_3_4_Phuong_thuc_tri_lieu_2026.docx` (cần gói npm `docx`).
  Script tự kiểm tra: tổng giờ LT/TH/tự học = 30/60/110 và tổng số phút hoạt động mỗi bài = số tiết × 50.

Căn cứ: Mẫu đề cương 2026; HD 292/HD-ĐHKTYDĐN (lựa chọn PPDH); HD 216/HD-ĐHKTYDĐN (đánh giá người học); HD 262/HD-ĐHKTYDĐN (rubric, checklist).
